# Architecture decision records

Approved decisions for Sylvia (plan Section 22.4). Copy `0000-template.md` for a new record. Numbers are assigned in advance during Stage 0 so parallel workstreams never collide.

**Accepted (22 October 2026).** On 22 October 2026 the product owner approved the M0 decisions on the M0 decision page, among them runbook decision D-6 as recommended: the Stage 0 records below are accepted, ADR-0002's amendments with them, and the device runbook's corrections C47, C49, C50 and C56 are applied to ADR-0009, ADR-0011, ADR-0013 and ADR-0010. What that means, and does not:

- **An accepted record can carry pending device confirmations.** Approving a decision is not a device result: every device and human step a record names stays pending in it until it runs, and a device result or review that contradicts a decision reopens it. The M0 exit still waits for every blocking device step of the runbook's Section 7 (decision D-10 (i)).
- **The plan 23.3 sign-offs are pending.** D-6's recommended default read "approve each ADR once Session 10's review of it is recorded". The review recorded on 22 October 2026 is the product owner's own (the decision page); the reviews of the plan 23.3 roles (security reviewer, QA, design, technical lead) are not. Sylvia is a solo project: the product owner signs each of those roles personally, and each is recorded only after the device sessions have produced the evidence that role signs; until then each stays pending, and each record names the ones it needs.
- **Every review so far was an agent's.** No independent person has reviewed any record here. An outside security review is recommended before any public release (plan 18.4: public App Store submission is a separate approval gate; ADR-0015, Open items).
- **The decisions that departed from the recommendations** are recorded where each applies: D-1 (b), device A is the iPhone 11 Pro (ADR-0001, and every record that named the iPhone 12-class baseline); PO-13 (b), the device inbox also read periodically in the background (ADR-0009); PO-23 (b), the locked-device test's harness built in Stage 0 (ADR-0012, ADR-0003); PO-39, the rewind after a long pause on by default and graduated (ADR-0006). PO-33, the onboarding samples, has no ADR.

Until 22 October 2026 every Stage 0 record after ADR-0002 was "Proposed": written and agent-reviewed, with the named deciders' approval still pending.
