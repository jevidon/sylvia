# G0.6 design tokens on devices: physical-device and human checklist

Everything here is **pending**. None of it was run in parts 1, 2 or 3: the physical iPhone is reserved for a later serialized run, the iPhone 12-class baseline and an iPad are not yet available (ADR-0001), and some checks need a person's judgement. Simulator results in `Docs/Stage0/G06-Design.md` are not device results.

**Prerequisite.** The design catalog app (`Apps/DesignCatalog`, G0.6 part 3) is the build for every step: its Colors page prints each token's resolved hex value from the compiled asset catalog and the contrast of every pair, the Type page the resolved sizes, then the marker set, the custom symbols, every component sample (the same samples the snapshot references show) and the interaction prototype. Install it from Xcode 27.0 on the device: `source Scripts/lib/env.sh; source Scripts/lib/xcodegen.sh; sylvia_generate Apps/DesignCatalog`, open `Apps/DesignCatalog/DesignCatalog.xcodeproj`, scheme DesignCatalog, team A4KBDX665Z, Run. Use the **system** settings named in each step, not the catalog's own switches (those are trait overrides for quick comparison; Color Filters cannot be set from an app at all).

**Recording.** Save screenshots and notes under `Docs/Stage0/evidence/G06-Design/device/` as `<step>-<device>-<os>.png` (under 2 MB each) and add one line per step to `device/results.md`: step number, device model and identifier, OS build, date, tester, pass or fail, and what differed. A tester who is not the design reviewer marks judgement steps "agent-reviewed" or "tester-reviewed; design sign-off pending" as appropriate.

- **A. Oldest supported iPhone** (iPhone 12 class, iOS 26.x): pending hardware (ADR-0001). Until it is available, record "blocked: no baseline device"; never substitute the iPhone 17 Pro result.
