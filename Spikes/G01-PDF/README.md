# G0.1 PDF spike (PDFKit)

Stage 0 harness for gate G0.1, PDF half: anchors for multiline, cross-column and rotated selections, Sylvia-side highlight records drawn as overlays, Unicode offsets, per-page extraction status, search mapping, protected/truncated files and link interception. Never shipped. Decision record: `Docs/ADRs/0005-pdf-reading-and-anchors.md`. Report: `Docs/Stage0/G01-PDF.md`.

## Layout

| Path | What |
| --- | --- |
| `project.yml` | XcodeGen project `G01PDF`: framework `PDFAnchorKit`, app `PDFSpikeHarness` (`com.jevidon.sylvia.spike.pdf`), unit tests `PDFAnchorKitTests` (hosted in the app), UI tests `PDFSpikeHarnessUITests`. No third-party packages. |
| `Sources/PDFAnchorKit/` | The adapter: open/validate (`PDFSourceDocument`), extraction (`PageTextExtractor`), anchors (`PDFAnchor`, `PDFAnchorBuilder`, `PDFAnchorResolver`), geometry (`PageGeometry`), Unicode offsets (`UnicodeOffsets`), overlays (`OverlayPDFDocument`, `OverlayPage`, `HighlightStyle`), store (`HighlightStore`), search (`LexicalSearch`), links (`LinkPolicy`, `LinkInterceptor`, `PDFActionAudit`). |
| `Sources/Harness/` | Reader harness: open a fixture, select, Highlight (edit menu or toolbar), stored highlights restored on launch, link interception with confirm-before-open, per-page status line. Registers the `sylvia-g01-canary` URL scheme so any URL PDFKit opens by itself comes back and is recorded. |
| `Tests/Unit/`, `Tests/UI/` | Automated tests; evidence files go to `$SYLVIA_G01_PDF_EVIDENCE_DIR`. |
| `Tools/make_pdf_fixtures.py` | Fixture generator (Python 3 standard library only, deterministic). |
| `Tools/tsan_control_unguarded.sh` | Thread Sanitizer control: builds a copy of the spike with the overlay mutex removed and expects a race report. |
| `Tools/summarize_crash_reports.py` | Summarizes `.ips` crash reports for evidence (standard library only). |
| `Fixtures/` | Committed generated fixtures (below). |

## Run

```sh
Scripts/ci.d/32-g01-pdf.sh          # or: Scripts/ci.sh g01-pdf
```

It checks that the committed fixtures regenerate byte-identically, generates the large PDF into the cache, regenerates the project, boots the simulator `Sylvia-M0-g01-pdf` (iPhone 17, iOS 26.5), runs all unit and UI tests, then runs `OverlayConcurrencyTests` again in a Thread Sanitizer build, failing on any failed, skipped or crashed test or sanitizer report. Logs: `.build/g01-pdf-logs/`; evidence: `.build/g01-pdf-evidence/` (set `G01_PDF_EVIDENCE_DIR` to change).
