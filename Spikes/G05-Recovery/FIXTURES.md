# G0.5 recovery spike: fixture provenance

The spike's only committed fixture. `Fixtures/LICENSES.md`, the shared provenance list that
CLAUDE.md names, has had a row for it since M0 integration (13 October 2026, "G0.5 Recovery").
That row is out of date: it says "Generated text and digests only", which omits the public-domain
quotations listed below, and it gives the SHA-256 of the file as it was before review round 4
(`eae90f68…e592`). The replacement row is requested from that file's owner, because the file is
outside this workstream's paths (`Docs/Stage0/G05-Recovery.md`, open questions). Until it is
applied, this file is the complete record.

**Public-domain text in the golden corpus** (and so in the fixture). Every quotation from
*Meditations* is George Long's translation (1862; public domain) as Standard Ebooks prints it in
the committed `Fixtures/epub/se-meditations.epub`, checked against that file:

- IV.17, verbatim: "Do not act as if thou wert going to live ten thousand years." (a quote capture).
- V.6, verbatim up to "come and see": "As a horse when he has run, a dog when he has tracked the
  game, a bee when it has made the honey, so a man when he has done a good act, does not call out
  for others to come and see", followed by test characters written for the corpus (a dash, letters
  with combining accents, an emoji ZWJ sequence with a skin-tone modifier, pointed Hebrew, 東京,
  Markdown metacharacters, a pipe and a second line; `GoldenCorpus.unicodeQuote`). It is an EPUB
  quote capture and the capture-backed context evidence `c1`; the crash drills prefix it with
  "Crash item n: " (generated at run time, not committed).
- V.6, abridged: "A horse when he has run, a dog when he has tracked the game…" (the source-text
  context evidence `c2`).
- Henry David Thoreau: "Simplify, simplify." (*Walden*, 1854, in a work note) and the word
  "sauntering" (*Walking*, 1862, a word capture); both public domain.

Until review round 4 the V.6 capture opened with "We ought to do good to others as simply as \"a
horse runs\"", a popular modern paraphrase of V.6 whose source was not recorded; the reviewer
found it in the previous file (`eae90f68…e592`). It was replaced by Long's wording above and the
fixture regenerated, so the paraphrase is in neither the corpus nor the committed file.

**Names and bibliographic facts** (not quotations): the titles *Meditations* and *Walden; or, Life
in the Woods*; Marcus Aurelius, George Long and Henry David Thoreau; the Standard Ebooks
identifier `marcus-aurelius/meditations/george-long` and the publisher name Standard Ebooks;
"LibriVox volunteers" as a narrator; and "Philosophize This!", a podcast's name, as the label of a
recommendation.

Everything else in the corpus (the other notes, the AI question and answers, recommendation
reasons, file names, labels, and the "Ødegård’s Field Notes" work and its author) was written for
the spike. Everything else the tests use is generated at test time into temporary directories
(stand-in media and cover bytes from `DeterministicBytes`, at most 3 MiB per file) and is not
committed.

**How this list was checked** (review round 4): every distinct TEXT value of the committed file
was listed with a read-only query (`sqlite3` in `mode=ro&immutable=1`, UUIDs and digests masked),
and compared with the previous file: only the V.6 capture's quoted text, its context evidence, its
locator's end offset and highlight, and the entity UUIDs differ.
